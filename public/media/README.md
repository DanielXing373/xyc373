# Media

Photos, videos, and PDFs used by the site. Paths are set in `src/content/site.ts`.

- `portrait.jpg` — hero
- `education/` — school marks
- `pgwhite/`, `vr/` — featured projects
- `print-3d/`, `rapid-prototyping/`, `ai-ethics/`, `figma-app/` — interests

Videos: H.264 MP4, 720p, `+faststart`, loudness normalized to about -24 LUFS. Never commit raw camera files; keep each video well under 50 MB. A `-poster.jpg` next to a video is shown before playback, and the video is not downloaded until played.
- `intern-1/`, `intern-2/`, `intern-3/` — internships

Résumé PDF: `public/resume.pdf`
